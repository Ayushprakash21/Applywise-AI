# AUTO-APPLY SECURITY, ACCURACY & SAFETY SAFEGUARDS

---

## 1. ETHICAL & PROFESSIONAL SAFEGUARDS

The ApplyVise Autopilot Agent enforces non-negotiable professional standards:
1. **Zero Hallucination:** The agent never invents skills, certifications, degrees, or employers.
2. **Ground-Truth Preservation:** Tailored resumes and cover letters are generated from verified candidate facts registered in `candidate_facts`.
3. **Tenant & Data Isolation:** All agent operations and database records are strictly scoped to the authenticated `user_id`.
4. **Anti-Bot Compliance:** The agent respects platform rate limits and never attempts to bypass CAPTCHA, Cloudflare Turnstile, or login walls.
5. **Immediate Stop Control:** Candidates can immediately pause or resume automation from the dashboard with one click.
